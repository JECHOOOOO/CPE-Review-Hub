# Freshman Content Research Report

**COLMS — CentOs Learning Management System**
**Reviewed:** 2026-09-30
**Purpose:** Select a coherent six-lesson scope per existing Freshman course before expanding the lesson content or writing database records. These references inform original explanations and examples; they are not copied as course text. COLMS has not been given the institution's own approved course syllabi, so the outline is a research-grounded proposal for faculty review, not a claim about the official CentOs syllabus.

## CPE 101 — Introduction to Computing

### Sources reviewed

1. **Unit 1: Introduction to Computing & Digital Literacy**
   Institution: Purdue University, Department of Computer Science
   URL: <https://www.cs.purdue.edu/outreach/indiana-4565-curriculum/unit-1-intro-computing.html>
   Verified: 2026-09-30. Topics: computing context, algorithms, hardware, software, operating systems, and evaluating technology for users and constraints.
2. **CS101 — Introduction to Computing Principles**
   Institution: Stanford University, Computer Science
   URL: <https://web.stanford.edu/class/cs101/>
   Verified: 2026-09-30. Topics: introductory computing, software and operating systems, hardware, data and storage, and digital media.
3. **CS2023: Computer Science Curricula**
   Institution: ACM, IEEE Computer Society, and AAAI joint task force
   URL: <https://csed.acm.org/> and <https://csed.acm.org/knowledge-areas/>
   Verified: 2026-09-30. Topics: core knowledge areas spanning architecture, systems, networking, security, software development, and society/professional practice.

### Proposed six-lesson structure

1. Computing, computational thinking, algorithms, and problem decomposition
2. Computer organization: processor, memory, storage, input/output, and buses
3. Binary, hexadecimal, text, images, and numeric representation
4. Software layers, operating systems, compilers, and application execution
5. Networks, the Internet, addressing, protocols, and cloud services
6. Cybersecurity, privacy, responsible use, and a system-level case study

**Why selected:** Purdue and Stanford introductory outlines support the foundation sequence from what computing is through hardware/software and data. CS2023 supports including systems, networks, security, and professional/social context. The topics provide prerequisites for later CPE programming and systems courses without trying to teach their full depth.

## CPE 102 — Computer Programming 1

### Sources reviewed

1. **6.096 Introduction to C++ — Syllabus**
   Institution: MIT OpenCourseWare, Electrical Engineering and Computer Science
   URL: <https://ocw.mit.edu/courses/6-096-introduction-to-c-january-iap-2011/pages/syllabus/>
   Verified: 2026-09-30. Topics/outcomes: basic C++ constructs, types including arrays and strings, debugging, memory awareness, object-oriented approaches, and small programs.
2. **6.S096 Effective Programming in C and C++ — Syllabus**
   Institution: MIT OpenCourseWare, Electrical Engineering and Computer Science
   URL: <https://ocw.mit.edu/courses/6-s096-effective-programming-in-c-and-c-january-iap-2014/pages/syllabus/>
   Verified: 2026-09-30. Topics: syntax, compilers, debugging, C++ object-oriented programming, memory management, and modern practices. Its prerequisite note makes it a progression/reference source rather than a beginner sequence.
3. **CS2023: Computer Science Curricula — Knowledge Areas**
   Institution: ACM, IEEE Computer Society, and AAAI joint task force
   URL: <https://csed.acm.org/knowledge-areas/>
   Verified: 2026-09-30. Topics: software development fundamentals, reading/writing programs, algorithmic foundations, testing, and programming-language foundations.

### Proposed six-lesson structure

1. Problem specifications, algorithms, pseudocode, flowcharts, compile/run/test cycle
2. C++ values, variables, types, expressions, console input/output, and validation
3. Boolean expressions and selection (`if`/`else`, `switch`) with boundary tests
4. Repetition (`while`, `do-while`, `for`), loop state, tracing, and termination
5. Functions, parameters, return values, scope, decomposition, and simple tests
6. One-dimensional arrays, traversal, bounds, and systematic debugging in a small integrated program

**Why selected:** The structure introduces problem-solving and core imperative programming before adding collections and debugging. It reserves pointer and object-lifetime detail for CPE 103, following MIT's broader C++ outcome progression and CS2023's early software-development emphasis.

## CPE 103 — Computer Programming 2

### Sources reviewed

1. **6.096 Introduction to C++ — Syllabus**
   Institution: MIT OpenCourseWare, Electrical Engineering and Computer Science
   URL: <https://ocw.mit.edu/courses/6-096-introduction-to-c-january-iap-2011/pages/syllabus/>
   Verified: 2026-09-30. Topics/outcomes: arrays, strings, pointers, memory allocation/deallocation, error isolation, object-oriented approaches, and small-scale programs.
2. **6.088 Introduction to C Memory Management and C++ Object-Oriented Programming**
   Institution: MIT OpenCourseWare, Electrical Engineering and Computer Science
   URL: <https://ocw.mit.edu/courses/6-088-introduction-to-c-memory-management-and-c-object-oriented-programming-january-iap-2010/>
   Verified: 2026-09-30. Topics: C++ classes and objects, encapsulation, constructors/destructors, and memory management.
3. **Recitation 2 — Foundations of Software Engineering**
   Institution: MIT OpenCourseWare, Civil and Environmental Engineering (notes authored by Petros Komodromos, University of Cyprus)
   URL: <https://ocw.mit.edu/courses/1-124j-foundations-of-software-engineering-fall-2000/pages/recitations/recitation_2/>
   Verified: 2026-09-30. Topics: functions, recursion, references, pointers, multidimensional arrays, dynamic memory, data structures, classes, and objects. The page is used as a topic reference; its legacy code is not copied.

### Proposed six-lesson structure

1. Multidimensional arrays, strings, and structured data processing (build on CPE 102 arrays)
2. Addresses, pointers, references, object lifetime, and safe dynamic storage
3. Structures, enumerations, and modeling related records
4. Classes, objects, encapsulation, constructors, and invariants
5. Recursion, base cases, call stack, and recursive problem decomposition
6. File input/output, validation, modular integration, testing, and debugging in a small C++ application

**Why selected:** CPE 103 deliberately begins from arrays and functions already encountered in CPE 102, then advances into memory, records, object-oriented design, recursion, and files. It avoids repeating beginner loops and conditionals as standalone units; those remain tools used in the larger applications.

## CPE 104 — Discrete Mathematics

### Sources reviewed

1. **6.042J Mathematics for Computer Science — Syllabus**
   Institution: MIT OpenCourseWare, EECS and Mathematics
   URL: <https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/pages/syllabus/>
   Verified: 2026-09-30. Topics/outcomes: logic, definitions and proofs, sets, functions, induction, modular arithmetic, graphs, counting, recurrences, and computational applications.
2. **MAT 243: Discrete Mathematical Structures**
   Institution: Arizona State University, School of Mathematical and Statistical Sciences
   URL: <https://math.asu.edu/mat243>
   Verified: 2026-09-30. Topics: logic, sets, functions, number theory, combinatorics, recursive algorithms, induction, and proof writing, with computing connections.
3. **CSC 104 — Discrete Mathematical Structures Syllabus**
   Institution: The City College of New York, Grove School of Engineering, Computer Science Department
   URL: <https://www.ccny.cuny.edu/compsci/csc-104-syllabus>
   Verified: 2026-09-30. Topics: logic and quantifiers, set theory, induction, relations and functions, counting, recurrence relations, graphs, and trees.

### Proposed six-lesson structure

1. Propositional logic, connectives, truth tables, equivalence, and inference
2. Sets, set operations, identities, Cartesian products, and finite-set modeling
3. Relations and functions: properties, representations, composition, and inverses
4. Proof methods and mathematical induction, including correctness-style arguments
5. Counting: sum/product rules, permutations, combinations, and inclusion–exclusion
6. Graphs and trees: representations, paths, connectivity, traversal models, and applications

**Why selected:** MIT, ASU, and CCNY independently support these standard discrete structures and their computing applications. The six units group proof with induction and graph theory with trees to preserve the six-lesson constraint while maintaining a prerequisite order. Modular arithmetic and recurrence details can appear as carefully scoped examples, but are not separate units in this short six-lesson version.

## Research limitations

- No official CentOs / COLMS department syllabus or approved course learning outcomes were provided or found in the project. Faculty should approve the proposed outline before it is treated as the institution's official curriculum.
- These sources verify broad topic selection, not the exact local semester plan or accreditation mapping.
- MIT OpenCourseWare pages were consulted for curriculum outcomes/topic lists. COLMS lesson prose and examples must be newly written and not copied from those pages.
- No image URL was guessed from a search result. The current reviewed manifest contains eight first-year visuals with direct Wikimedia media links, file-page attribution, and licenses. These direct files were verified from the Commons file pages; an individual image was not manually opened in the deployed Student lesson browser, so runtime rendering remains an integration check.
